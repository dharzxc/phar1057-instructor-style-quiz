# PHAR1057 — Instructor-Style Mock Quiz

A self-contained, mobile-friendly practice quiz for Practical Nursing pharmacology topics.

- 20 original questions (single choice, select all that apply, matching, ordering, short response).
- Immediate self-grading with explanations and correct-answer review after submission.
- Covers coagulation modifiers, antihypertensives/dysrhythmics, nitrates, digoxin, and antilipemics.
- Does not require an account; progress stays in each user's browser.
- No external scripts, trackers, or dependencies. Just open `index.html`.

**Educational use only.** This independent practice site is not an official George Brown College exam or medication-administration reference.
